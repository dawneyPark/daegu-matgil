# 대구 맛길

대구 10미(味)와 골목·시장 맛집을 지역과 메뉴별로 찾아보는 안내 사이트입니다.

**사이트 주소:** https://dawneypark.github.io/daegu-matgil/

## 기능
- 대구 10미: 찜갈비, 따로국밥, 막창구이, 뭉티기, 복어불고기, 논메기매운탕, 누른국수, 무침회, 야끼우동, 납작만두
- 지역(구·군)·종류별 필터와 검색
- "오늘 뭐 먹지?" 랜덤 추천, 찜하기
- 네이버 지도·카카오맵 바로가기

## 가게 추가·수정
`index.html` 안의 `PLACES` 목록에 항목을 추가하거나 고치면 됩니다. 별도 빌드 과정은 없습니다.
