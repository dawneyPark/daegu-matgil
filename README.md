# 대구 맛길

청첩장에 넣어 하객분들께 소개하는, 저희가 좋아하는 곳과 대구에서 이름난 맛집 모음입니다. 휴대폰 화면 기준으로 디자인했습니다.

**사이트 주소:** https://dawneypark.github.io/daegu-matgil/

## 기능
- 지역(구·군)·종류별 필터와 검색
- 종류: 곱창·막창, 고기, 치킨, 한식·분식, 중식, 라멘·텐동, 피자·버거, 다이닝, 카페·브런치
- 대구 10미(찜갈비, 막창구이 등)에 해당하는 가게는 태그로 표시
- 네이버 지도·카카오맵 바로가기
- 위쪽 탭으로 "맛집" / "구경할 곳"(옷가게·소품 가게, `SHOPS` 목록) 전환. 주소 끝에 `#shops`를 붙이면 구경할 곳 탭으로 바로 열림

## 가게 추가·수정
`index.html` 안의 `PLACES` 목록에 항목을 추가하거나 고치면 됩니다. 별도 빌드 과정은 없습니다.

> 영업시간과 휴무일은 자주 바뀝니다. 방문 전 지도에서 최신 정보를 확인하세요.
